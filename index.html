조작법 안내

화면 조작

  • 휠클릭 또는 Ctrl+좌클릭 드래그 — 화면 이동(팬)
  • 스크롤 — 확대 / 축소(커서 위치 기준)
  • 우측 상단 화면 초기화 버튼 — 팬/줌 초기화

생성 / 편집

  • 빈 곳 더블클릭 — 메모 생성(현재 도형으로)
  • 빈 곳 우클릭 — 퀵메뉴(메모 추가 / 도형 전환)
  • 1 / 2 / 3 또는 우측 상단 도형 아이콘 클릭 — 다음 생성 도형 전환(사각형/원/마름모)
  • 메모 더블클릭 — 텍스트 편집

선택 / 이동

  • 메모 클릭 — 선택, 드래그 — 이동(여러 개 선택 시 다같이)
  • 빈 곳 드래그 — 영역으로 여러 메모 선택
  • Shift+클릭(메모) — 선택 추가/제거, Shift+드래그(빈 곳) — 영역에 걸린 것만 토글
  • 선택 후 모서리 핸들 드래그 — 크기 조절(Shift = 비율 유지)
  • Delete / Backspace — 선택된 메모/화살표 삭제

화살표

  • 메모 우클릭 — 연결 시작, 다른 메모 클릭으로 완성(Esc/빈 곳 클릭 취소)
  • 화살표 클릭 — 선택
  • 화살표 더블클릭 — 라벨 입력(Enter 저장 / Esc 취소)

히스토리

  • Ctrl+Z — 실행취소
  • Ctrl+Shift+Z 또는 Ctrl+Y — 다시실행

꾸미기

  • 메모 선택 시 사이드바 꾸미기 패널 — 배경색 / 텍스트 크기 / 정렬 / 테두리 굵기 조절

사이드바

  • 페이지/폴더 더블클릭 또는 펜 아이콘 — 이름 변경
  • 페이지를 폴더 위로 드래그 — 이동, Ctrl/Shift+클릭 — 다중 선택
  • 하단 내보내기 / 가져오기 — 전체 백업
  • Ctrl+B — 사이드바 접기/펼치기

검색

  • 사이드바 상단 검색창 — 페이지/폴더 검색
  • Ctrl+F 또는 우측 상단 🔍 — 현재 페이지 메모 검색(Enter 다음 결과, Esc 닫기)

Mermaid 내보내기 (클로드와 주고받기)

  • Tab 또는 우측 상단 토글 — 다음에 만들 도형의 다이어그램 타입(플로우차트/마인드맵) 전환
  • L 또는 ◌ 올가미 — 올가미 모드(Esc로 해제). 감싼 도형이 전부 미배정이면 새 그룹이 생기고(타입이 섞여 있으면 타입별로 나뉨, 미지정 도형은 같이 묶인 쪽 타입을 따라감), 이미 있는 그룹의 도형이 걸리면 새로 만들지 않고 미배정 도형만 그 그룹에 편입되며, 서로 다른 그룹 여러 개가 걸리면 멤버가 더 많은 그룹으로 합쳐진다
  • 그룹 박스의 이름 더블클릭 — 이름 변경(Mermaid 의 subgraph 이름이 된다), × — 그룹 해제
  • 그룹 우클릭(박스나 이름표) — 전체 선택 / 이름 변경 / 타입 전환(마인드맵 전환 시 트리가 아니면 거부) / 그룹 복제(도형+화살표+배치를 그대로 복사) / 잠그기·잠금 해제 / 그룹 해제
  • 잠긴(🔒) 그룹은 올가미로 도형을 추가/제거할 수 없고, 그 도형은 드래그로 옮길 수도 없다
  • 이미 만든 도형의 타입은 꾸미기 패널에서도 변경 가능(그룹에 속한 도형이면 그룹 전체가 함께 바뀐다)
  • 도형을 드래그해 그룹 이름표 위에 놓으면 그 그룹에 바로 편입된다(놓기 전에 이름표가 강조 표시됨)
  • 그룹 배경 안(이름표 아닌 곳)을 우클릭하면 안내가 뜨고, "여기에 메모 추가"로 만든 메모가 그 그룹에 바로 편입된다
  • 그룹 소속 도형에 마우스를 올리면 삭제(×) 버튼 옆에 − 버튼이 나타난다 — 클릭하면 그 도형만 그룹에서 빠지고(삭제 아님) 박스는 남은 멤버 기준으로 다시 계산된다. 같은 동작을 꾸미기 패널의 "그룹에서 빼기" 버튼으로도 할 수 있다(다중 선택 시 그룹에 속한 것만 전부 빠짐). 그룹에 도형이 하나도 안 남으면 그룹 자체가 사라진다
  • ⤴ Mermaid — 현재 페이지를 Mermaid 텍스트로 변환해 보여준다. 블록마다 복사 버튼이 있고, 변환에서 빠진 것이 있으면 위쪽에 알려준다
  • 마인드맵 그룹은 화살표가 하나의 중심에서 뻗어나가는 트리여야 한다(순환하거나 화살표가 두 개 들어오면 변환되지 않는다)
