화면 조작

  • 휠클릭 또는 Ctrl+좌클릭 드래그 — 화면 이동(팬)
  • 스크롤 — 확대 / 축소(커서 위치 기준)
  • 우측 상단 화면 초기화 버튼 — 팬/줌 초기화

생성 / 편집

  • 빈 곳 더블클릭 — 메모 생성(현재 도형으로)
  • 빈 곳 우클릭 — 퀵메뉴(메모 추가 / 도형 전환 / 올가미로 그룹 만들기 — 클릭하면 바로 올가미 모드로 전환)
  • 1~6 또는 우측 상단 도형 아이콘 클릭 — 다음 생성 도형 전환(단계/분기/시작·끝/준비·설정/입력/출력, Mermaid 표준 도형 이름)
  • 메모 더블클릭 — 텍스트 편집
  • 메모 Shift+우클릭 — 다이어그램 타입(플로우차트/마인드맵) 빠른 선택 메뉴(꾸미기 패널과 같은 동작 — 다중 선택·그룹 전체 적용도 동일). Shift 없는 보통 우클릭은 그대로 화살표 연결 시작
  • 도형 높이는 항상 지금 텍스트 양에 맞춰 자동으로 계산된다(너비는 그대로) — 텍스트가 늘면 커지고, 줄면 다시 기본 크기로 작아진다. 모서리를 드래그해서 수동으로 리사이즈한 도형은 그 순간부터 자동 조정에서 빠지고 그 크기가 계속 유지된다

선택 / 이동

  • 메모 클릭 — 선택, 드래그 — 이동(여러 개 선택 시 다같이)
  • 빈 곳 드래그 — 영역으로 여러 메모 선택
  • Shift+클릭(메모) — 선택 추가/제거, Shift+드래그(빈 곳) — 영역에 걸린 것만 토글
  • 선택 후 모서리 핸들 드래그 — 크기 조절(Shift = 비율 유지)
  • Delete / Backspace — 선택된 메모/화살표 삭제

화살표

  • 메모 우클릭 — 연결 시작, 다른 메모 클릭으로 완성(Esc/빈 곳 클릭 취소). 연결 지점은 두 도형의 중심을 잇는 직선이 각 도형의 실제 윤곽과 만나는 지점(Mermaid 실제 렌더링과 비슷하게, 상/하/좌/우 고정 지점이 아니다)
  • 화살표 클릭 — 선택(선택되면 × 버튼이 나타나 클릭 한 번으로 삭제 가능, Delete 키도 그대로 동작)
  • 화살표 더블클릭 — 라벨 입력(Enter 저장 / Esc 취소)

히스토리

  • Ctrl+Z — 실행취소
  • Ctrl+Shift+Z 또는 Ctrl+Y — 다시실행

꾸미기

  • 메모 선택 시 사이드바 꾸미기 패널 — 다이어그램 타입(플로우차트/마인드맵/미지정) 조절, "그룹에서 빼기" 버튼

사이드바

  • 페이지/폴더 더블클릭 또는 펜 아이콘 — 이름 변경
  • 페이지를 폴더 위로 드래그 — 이동, Ctrl/Shift+클릭 — 다중 선택
  • 하단 내보내기 / 가져오기 — 전체 백업
  • Ctrl+B — 사이드바 접기/펼치기

검색

  • 사이드바 상단 검색창 — 페이지/폴더 검색
  • Ctrl+F 또는 우측 상단 🔍 — 현재 페이지 메모 검색(Enter 다음 결과, Esc 닫기)

Mermaid 내보내기 (클로드와 주고받기)

  • Tab 또는 우측 상단 토글 — 다음에 만들 도형의 다이어그램 타입(플로우차트/마인드맵) 전환
  • 도형 자체의 생김새는 다이어그램 타입과 무관하게 항상 같다(6종 모양 그대로) — 타입 구분은 그룹 이름표의 모양(플로우차트=각진 배지, 마인드맵=둥근 캡슐 배지)과 타입 아이콘(🔀 플로우차트 / 🧠 마인드맵)이 맡는다. 그룹 배경색 자체는 타입과 무관하게 항상 같다
  • L, 툴바 ◌ 올가미, 또는 빈 곳 우클릭 퀵메뉴의 올가미로 그룹 만들기 — 올가미 모드(Esc로 해제, 그룹을 하나 묶으면 자동으로 선택 모드로 돌아간다). 감싼 도형이 전부 미배정이면 새 그룹이 생기고(타입이 섞여 있으면 타입별로 나뉨, 미지정 도형은 같이 묶인 쪽 타입을 따라감), 이미 있는 그룹의 도형이 걸리면 새로 만들지 않고 미배정 도형만 그 그룹에 편입되며, 서로 다른 그룹 여러 개가 걸리면 멤버가 더 많은 그룹으로 합쳐진다
  • 그룹 박스의 이름 더블클릭 — 이름 변경(Mermaid 의 subgraph 이름이 된다), × — 그룹 해제
  • 그룹 우클릭(박스나 이름표) — 전체 선택 / 이름 변경 / 타입 전환(마인드맵 전환 시 트리가 아니면 거부) / 그룹 복제(도형+화살표+배치를 그대로 복사) / 잠그기·잠금 해제 / 그룹 해제
  • 잠긴(🔒) 그룹은 올가미로 도형을 추가/제거할 수 없고, 그 도형은 드래그로 옮길 수도 없다
  • 이미 만든 도형의 타입은 꾸미기 패널에서도 변경 가능(그룹에 속한 도형이면 그룹 전체가 함께 바뀐다)
  • 도형에 마우스를 올리면 소속 그룹 이름이 툴팁으로 뜬다(그룹이 없으면 안 뜬다)
  • 도형을 드래그해 그룹 이름표 위에 놓으면 그 그룹에 바로 편입된다(이름표가 커지며 강조되고, 커서 옆에도 "OO 그룹에 추가" 배지가 뜬다)
  • 그룹 배경 안(이름표 아닌 곳)을 우클릭하면 안내가 뜨고, "여기에 메모 추가"로 만든 메모가 그 그룹에 바로 편입된다
  • 그룹 소속 도형에 마우스를 올리면 삭제(×) 버튼 옆에 − 버튼이 나타난다 — 클릭하면 그 도형만 그룹에서 빠지고(삭제 아님) 박스는 남은 멤버 기준으로 다시 계산된다. 같은 동작을 꾸미기 패널의 "그룹에서 빼기" 버튼으로, 또는 2개 이상 선택했을 때 선택 경계 상자 우측 상단에 나타나는 같은 모양(원형 −)의 버튼으로도 할 수 있다(셋 다 다중 선택 시 그룹에 속한 것만 전부 빠짐). 그룹에 도형이 하나도 안 남으면 그룹 자체가 사라진다
  • 2개 이상 선택 시 그 − 버튼 오른쪽에 × 버튼도 함께 뜬다(그룹 소속 여부 무관) — 클릭하면 선택된 도형 전부와 딸린 화살표가 한 번에 삭제된다(Delete 키와 동일)
  • 그룹에 속하지 않은 도형은 테두리가 점선 + 주황색으로 표시된다(단계/시작·끝은 점선 테두리, 분기/준비·설정/입력/출력은 배경 전체가 주황색 — 배경색으로 테두리를 흉내내는 도형이라 점선을 못 써서). 그룹에 속한 도형은 실선 테두리 그대로
  • ⇄ 재배치 — 선택된 도형(딱 선택된 것만, 그룹으로 확장 안 됨)이나 페이지 전체를 Mermaid 배치 규칙대로 다시 정렬한다. 대상 그룹의 타입에 따라 알고리즘이 자동으로 갈린다 — 플로우차트는 dagre(계층형), 마인드맵은 d3-hierarchy(방사형, 루트가 중심·자식이 둘레에 균등 각도로 배치). 확인 메시지 후 실행되며, 도형을 지우고 새로 만들지 않아 배경색·자동크기 상태는 그대로 유지된다
  • ⤴ Mermaid — 현재 페이지를 Mermaid 텍스트로 변환해 보여준다. 블록마다 복사 버튼이 있고, 변환에서 빠진 것이 있으면 위쪽에 알려준다
  • 마인드맵 그룹은 화살표가 하나의 중심에서 뻗어나가는 트리여야 한다(순환하거나 화살표가 두 개 들어오면 변환되지 않는다)
  • 마인드맵 문법에서 단계/분기/시작·끝/준비·설정은 각각 다른 도형 모양(사각형/둥근 사각형/원/육각형)으로 정확히 왕복된다. 입력/출력만 마인드맵엔 구분되는 모양이 없어 둘 다 사각형으로 대체된다(재배치하면 실제 도형도 사각형으로 바뀐다) — 실제로 쓰였을 때만 위쪽에 경고로 알려준다
  • ⤵ Mermaid 가져오기 — Mermaid 텍스트(flowchart/mindmap)를 붙여넣으면 좌표를 자동 계산해 도형·화살표·그룹으로 만든다. flowchart 의 subgraph 는 그룹이 되고, subgraph 밖 낱개 도형은 "가져온 도형" 그룹으로 따로 묶인다(가져온 도형은 예외 없이 항상 어떤 그룹엔가 속한다) — mindmap 은 통째로 그룹 하나가 된다. 기존 캔버스 내용과 안 겹치는 빈 자리(오른쪽 또는 아래쪽)에 배치되고, 다 만든 뒤엔 화면이 그 자리로 바로 이동한다. 텍스트 안의 <br/>·<br> 는 실제 줄바꿈으로 바뀌고, 각 도형은 그 텍스트가 잘리지 않을 만큼 충분한 크기로 만들어진다. 새로 만들어진 도형은 이동·크기조절·타입변경·삭제 등 기존 도형과 완전히 동일하게 다룰 수 있다. 파싱하지 못한 줄이 있으면 그 부분만 건너뛰고 나머지는 최대한 가져오며, 무엇을 건너뛰었는지 알려준다
  • 도형 텍스트 안의 실제 줄바꿈은 내보내기(Export) 할 때 <br/> 로 바뀌어 Mermaid 문법을 유지한다(가져오기와 정확히 반대 방향)
