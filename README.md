# bluishCanvas

무한 캔버스 위에 도형과 텍스트를 배치하고 화살표로 연결하는 개인용 시각적 메모 도구.

## 실행 방법

빌드 과정이 없다. `index.html` 파일을 웹 브라우저로 열면 된다.
(파일 탐색기에서 더블클릭하거나, 브라우저 창에 드래그 앤 드롭)

## 현재 구현된 기능 (1단계 + 조작 개선 + 다중 선택 + 실행취소 + 크기 조절)

| 동작 | 방법 |
|---|---|
| 화면 이동 (팬) | **휠(가운데) 버튼** 드래그, 또는 **Ctrl + 왼쪽 버튼** 드래그 |
| 확대 / 축소 (줌) | 마우스 스크롤 (커서 위치 기준) |
| 메모 생성 | 빈 곳 더블클릭 |
| 메모 선택 (단일) | 메모를 (좌)클릭 |
| 메모 선택 (다중) | 빈 곳을 (좌)드래그해 사각형 영역으로 여러 메모를 한 번에 선택 |
| 선택 추가/제거 | **Shift**+메모 클릭 — 그 메모만 선택에 추가되거나(안 되어 있었으면) 빠짐(되어 있었으면). 이동은 시작되지 않음 |
| 선택 영역 추가 | **Shift**+빈 곳 드래그 — 기존 선택은 유지한 채, 새 영역에 걸리는 메모가 더해짐 |
| 선택 해제 | 빈 곳 클릭 (Shift를 누른 채면 해제되지 않음) |
| 메모 편집 | 메모 더블클릭 후 입력 (한 번에 하나씩만 가능) |
| 메모 이동 | 선택된 메모(들)를 드래그 — 여러 개가 선택되어 있으면 다같이 이동 |
| 메모 크기 조절 | 선택하면 모서리에 나타나는 핸들을 드래그. 기본은 가로/세로 자유 조절, **Shift**+드래그면 원래 비율 유지. 여러 개가 선택되어 있으면 선택 영역 전체를 하나의 사진처럼 확대/축소하듯 위치와 크기, 메모 사이 간격까지 함께 비례해서 바뀜 |
| 메모 삭제 | 선택 후 Delete/Backspace(선택된 메모 전부 삭제), 또는 메모에 마우스를 올렸을 때 나오는 × 버튼 클릭(그 메모만 삭제) |
| 실행취소 | Ctrl+Z |
| 다시실행 | Ctrl+Shift+Z 또는 Ctrl+Y |
| 화면 초기화 | 우측 상단 버튼 |

오른쪽 버튼은 지금은 예약만 되어 있고 동작이 없다 (다음 단계에서 메모 사이 화살표 연결에 배정 예정).

여러 메모에 한 번에 서로 다른 텍스트를 입력하는 기능은 없다. 텍스트 편집은 항상 메모 하나씩 더블클릭해서 한다.

실행취소/다시실행은 메모의 생성·이동·삭제·텍스트 수정만 기록한다 (화면 이동·확대축소는 기록되지 않음).
텍스트 수정은 글자 하나하나가 아니라 편집을 마치고 메모 밖을 클릭했을 때 한 단계로 기록된다.
기록은 최근 50단계까지만 유지되며, 브라우저를 새로고침하면 초기화된다(저장되는 내용 자체는 유지됨).

작업 내용은 브라우저 `localStorage` 에 자동 저장되어 새로고침해도 유지된다.
(저장 위치는 브라우저별로 분리됨. 다른 브라우저/기기와는 공유되지 않음)

## 기술 스택

- 순수 HTML / CSS / JavaScript, 빌드 도구·서버 없음
- 무한 캔버스는 `#world` 컨테이너에 CSS `transform: translate() scale()` 을 적용해 구현
- 상태: `view = { x, y, scale }` + `notes = [{ id, x, y, w, h, text }]`

## 파일 구조

```
index.html   화면 뼈대
styles.css   스타일 (점 격자 배경, 메모 카드)
app.js       로직 전체 (팬 / 줌 / 생성 / 이동 / 선택 / 삭제 / 실행취소 / 저장)
```
