# bluishCanvas

무한 캔버스 위에 도형과 텍스트를 배치하고 화살표로 연결하는 개인용 시각적 메모 도구.

## 실행 방법

빌드 과정이 없다. `index.html` 파일을 웹 브라우저로 열면 된다.
(파일 탐색기에서 더블클릭하거나, 브라우저 창에 드래그 앤 드롭)

## 현재 구현된 기능 (1단계)

| 동작 | 방법 |
|---|---|
| 화면 이동 (팬) | 빈 곳을 마우스로 드래그 |
| 확대 / 축소 (줌) | 마우스 스크롤 (커서 위치 기준) |
| 메모 생성 | 빈 곳 더블클릭 |
| 메모 편집 | 메모 더블클릭 후 입력 |
| 메모 이동 | 메모를 드래그 |
| 화면 초기화 | 우측 상단 버튼 |

작업 내용은 브라우저 `localStorage` 에 자동 저장되어 새로고침해도 유지된다.
(저장 위치는 브라우저별로 분리됨. 다른 브라우저/기기와는 공유되지 않음)

## 기술 스택

- 순수 HTML / CSS / JavaScript, 빌드 도구·서버 없음
- 무한 캔버스는 `#world` 컨테이너에 CSS `transform: translate() scale()` 을 적용해 구현
- 상태: `view = { x, y, scale }` + `notes = [{ id, x, y, text }]`

## 파일 구조

```
index.html   화면 뼈대
styles.css   스타일 (점 격자 배경, 메모 카드)
app.js       로직 전체 (팬 / 줌 / 생성 / 이동 / 저장)
```
