# bluishCanvas

무한 캔버스 위에 도형과 텍스트를 배치하고 화살표로 연결하는 개인용 시각적 메모 도구.
여러 개의 캔버스("페이지")를 만들고 폴더로 정리할 수 있다.

**배포 주소 (GitHub Pages):** https://bluishgrey.github.io/bluishCanvas/

## 실행 방법

빌드 과정이 없다. `index.html` 파일을 웹 브라우저로 열면 된다.
(파일 탐색기에서 더블클릭하거나, 브라우저 창에 드래그 앤 드롭)

또는 위 배포 주소로 바로 접속해서 브라우저에서 열 수도 있다. 다만 이 경우 데이터는
그 브라우저의 `localStorage` 에 저장되므로, 로컬로 열었을 때와 페이지를 열 때마다
사용한 방식(파일 직접 열기 vs 배포 주소)에 따라 서로 다른 저장 공간을 쓴다는 점에
주의한다(둘 사이 데이터 이동은 내보내기/가져오기 사용).

## 현재 구현된 기능 (1단계 + 조작 개선 + 다중 선택 + 실행취소 + 크기 조절 + 도형 + 화살표 + 페이지/폴더 + 백업 + 꾸미기 + 검색 + UI 개선)

| 동작 | 방법 |
|---|---|
| 사이드바 페이지/폴더 검색 | 사이드바 상단 검색창에 입력하면 이름이 일치하는 페이지/폴더만 트리에 남고 나머지는 숨겨진다. 일치하는 페이지가 들어있는 폴더는 자동으로 펼쳐져서 보인다. 검색창을 비우면 원래 전체 트리(펼침/접힘 상태 포함)로 돌아온다 |
| 캔버스 메모 검색 | **Ctrl+F** 또는 우측 상단 **🔍** 버튼을 누르면 화면 위쪽에 검색창이 뜬다(브라우저 기본 찾기 대신). 입력하면 현재 페이지 안에서 텍스트가 일치하는 메모들이 노란 테두리로 하이라이트되고 첫 번째 결과로 화면이 자동으로 이동한다. **Enter**(다음)/**Shift+Enter**(이전)로 결과 사이를 순환 이동, **Esc**로 검색창을 닫는다 |
| 조작법 안내 | 화면 우측 하단 **?** 버튼을 누르면 그 바로 위에 조작법 안내 팝업이 뜬다(화면을 어둡게 덮지 않음). 내용은 화면조작/생성편집/선택이동/화살표/히스토리/꾸미기/사이드바/검색 항목별로 나뉘어 있다. 팝업 바깥을 클릭하거나 **Esc** 로 닫힌다 |
| 메모 꾸미기 | 메모(들)를 선택하면 사이드바 하단 **꾸미기** 패널에 배경색(흰색/노랑/초록/빨강/파랑)·텍스트 크기(작게/보통/크게)·텍스트 정렬(왼쪽/가운데/오른쪽)·테두리 굵기(얇게/보통/굵게)가 나타나 바로 조절할 수 있다. 여러 메모가 선택돼 있으면 전부 동일하게 적용된다. 선택이 없으면 "메모를 선택하세요" 안내만 보인다. 변경은 실행취소(Ctrl+Z) 대상이고, 저장/내보내기·가져오기에도 함께 포함된다 |
| 전체 내보내기 | 사이드바 하단 **⬇ 내보내기** 버튼 — 모든 페이지/폴더/메모/화살표를 JSON 파일 하나로 다운로드. 파일명에 날짜·시간이 들어간다(`bluishCanvas-backup-2026-09-12_161653.json`). 완료되면 파일명이 담긴 확인 메시지가 뜬다 |
| 전체 가져오기 | 사이드바 하단 **⬆ 가져오기** 버튼 → JSON 파일 선택. 이름이 겹치는 페이지/폴더가 있으면 각각 "덮어쓰기" 또는 "새 이름으로 추가"(예: `CS50` → `CS50 2`)를 물어보고, 겹치지 않으면 그냥 추가한다. 가져온 항목은 항상 새 id를 받아서 기존 데이터와 충돌하지 않는다. 완료되면 가져온 페이지/폴더 개수가 담긴 확인 메시지가 뜬다 |
| 최근 백업 기록 표시 | 사이드바 맨 아래에 "마지막 내보내기"/"마지막 가져오기" 시각이 작게 표시된다(각각 하나씩만, 전체 기록 아님). 이 정보는 내보내기 파일 안에도 같이 저장되어, 다른 컴퓨터에서 그 파일을 가져오면 "마지막 내보내기 기록"도 함께 이어진다(마지막 가져오기 기록은 그 컴퓨터에서 실제로 가져온 시점으로 새로 기록됨) |
| 페이지 생성 | 좌측 사이드바 상단 **＋▭** 버튼(맨 위 단계에 생성), 또는 폴더에 마우스를 올렸을 때 나오는 **＋▭** |
| 폴더 생성 | 사이드바 상단 **＋▤** 버튼, 또는 폴더 위 **＋▤** (폴더 안에 폴더도 중첩 가능) |
| 페이지 전환 | 사이드바에서 페이지 이름 클릭. 지금 열려 있는 페이지는 강조 표시됨 |
| 폴더 펼치기/접기 | 폴더 행 클릭(이름 포함) 또는 세모(▸/▾) 클릭 |
| 이름 변경 | 페이지/폴더 이름 **더블클릭**, 또는 행에 마우스를 올리면 나오는 **✎** 버튼 → 입력 → Enter(저장)/Esc(취소) |
| 페이지/폴더 삭제 | 행에 마우스를 올리면 나오는 **×** 버튼. 폴더 삭제 시 안의 페이지도 모두 함께 삭제되며, 페이지가 하나라도 있으면 확인창이 뜬다. 마지막 남은 페이지는 삭제할 수 없다 |
| 사이드바 다중 선택 | **Ctrl+클릭**으로 항목을 선택에 추가/제거, **Shift+클릭**으로 마지막 선택 지점부터 범위 선택 |
| 항목을 폴더 안으로 이동 | 페이지/폴더 행을 **드래그**해 다른 폴더 행의 **가운데**에 놓기(그 폴더가 파란 점선으로 강조됨). 여러 개를 선택한 채로 드래그하면 다같이 이동 |
| 항목 순서 이동 / 계층 이동 | 행을 다른 행의 **위쪽/아래쪽 가장자리**(좁은 틈)에 놓으면 그 자리로 순서가 바뀐다 — 같은 계층이면 순서만, 다른 계층의 틈이면 그 계층으로 이동하며 순서도 반영됨. 자리 표시는 얇은 파란 선으로 나타난다 |
| 항목을 폴더 밖(최상위)으로 이동 | 사이드바 맨 아래 빈 공간이나 최상위 항목들 사이로 드래그 |
| 사이드바 접기/펼치기 | 사이드바 상단의 **☰** 버튼, 접혀 있을 때는 화면 좌상단에 남아있는 **☰** 버튼, 또는 **Ctrl+B** |
| 화면 이동 (팬) | **휠(가운데) 버튼** 드래그, 또는 **Ctrl + 왼쪽 버튼** 드래그 |
| 확대 / 축소 (줌) | 마우스 스크롤 (커서 위치 기준) |
| 메모 생성 | 빈 곳 더블클릭 — 현재 "다음 생성 도형"으로 생성됨 |
| 다음 생성 도형 전환 | 숫자 **1**(사각형) / **2**(원) / **3**(마름모), 우측 상단 미니 팔레트의 도형 아이콘 클릭, 또는 빈 곳 **우클릭** 퀵메뉴에서 선택 — 셋 다 완전히 동일하게 동작하고 항상 서로 맞춰 표시된다. 팔레트 아이콘 모서리에 단축키 숫자가 작게 표시되고, 현재 도형은 강조색으로 표시됨 |
| 빈 곳 우클릭 퀵메뉴 | "여기에 메모 추가"(그 자리에 현재 도형으로 생성) + 도형 전환 항목 |
| 화살표 연결 | 메모를 **우클릭**하면 연결 모드로 들어가 커서를 따라 점선이 나타남. 다른 메모를 클릭하면 그 메모로 연결 완성(화살촉은 도착 쪽), **빈 곳 클릭**이나 **Esc**로 취소. 연결 지점은 두 메모의 상대 위치에 따라 상/하/좌/우 중 가장 자연스러운 쪽이 자동으로 정해지고, 메모를 옮기거나 크기를 바꾸면 매번 다시 계산된다 |
| 화살표 선택 | 화살표 선 아무 곳이나 클릭(약간의 클릭 허용 오차 있음). 영역(드래그) 선택 시에는 화살표의 중앙점이 영역 안에 들어와야 선택됨 |
| 화살표 삭제 | 선택 후 Delete/Backspace. 연결된 메모를 삭제하면 그 화살표도 자동으로 함께 삭제됨 |
| 화살표 라벨 | 화살표를 **더블클릭**하면 중간에 작은 입력칸이 뜬다. 짧은 텍스트(예: "예", "아니오", "완료")를 입력하고 Enter(저장)/Esc(취소), 또는 다른 곳을 클릭해도 저장된다. 짙은 남색 배경 + 밝은 텍스트의 알약(캡슐) 모양 다크 칩으로 화살표 중간에 표시되어(메모 카드와는 다른, "보조 정보" 느낌. 테두리/그림자 없음) 화살표가 움직이면 같이 따라간다. 입력칸을 비우고 저장하면 라벨이 없어져서 기존처럼 선만 남는다 |
| 메모 선택 (단일) | 메모를 (좌)클릭 |
| 메모 선택 (다중) | 빈 곳을 (좌)드래그해 사각형 영역으로 여러 메모를 한 번에 선택 |
| 선택 추가/제거 | **Shift**+메모 클릭 — 그 메모만 선택에 추가되거나(안 되어 있었으면) 빠짐(되어 있었으면). 이동은 시작되지 않음 |
| 선택 영역 토글 | **Shift**+빈 곳 드래그 — 영역에 걸린 메모만 각각 토글(선택 안 돼 있었으면 추가, 돼 있었으면 해제). 영역 밖의 기존 선택은 그대로 유지 |
| 선택 해제 | 빈 곳 클릭 (Shift를 누른 채면 해제되지 않음) |
| 메모 편집 | 메모 더블클릭 후 입력 (한 번에 하나씩만 가능) |
| 메모 이동 | 선택된 메모(들)를 드래그 — 여러 개가 선택되어 있으면 다같이 이동 |
| 메모 크기 조절 | 선택하면 모서리에 나타나는 핸들을 드래그. 기본은 가로/세로 자유 조절, **Shift**+드래그면 원래 비율 유지. 여러 개가 선택되어 있으면 선택 영역 전체를 하나의 사진처럼 확대/축소하듯 위치와 크기, 메모 사이 간격까지 함께 비례해서 바뀜 |
| 메모 삭제 | 선택 후 Delete/Backspace(선택된 메모 전부 삭제), 또는 메모에 마우스를 올렸을 때 나오는 × 버튼 클릭(그 메모만 삭제) |
| 실행취소 | Ctrl+Z |
| 다시실행 | Ctrl+Shift+Z 또는 Ctrl+Y |
| 화면 초기화 | 우측 상단 버튼 |

빈 곳 우클릭은 퀵메뉴를 열고, 메모 위 우클릭은 화살표 연결 모드를 시작한다. 화살표는 단방향(시작 → 끝)만 지원하며,
메모 하나를 다른 여러 메모와 연결하는 것도 가능하다. 이미 만든 화살표의 시작/끝 메모를 나중에 바꾸는 기능은 없다
(화살표를 지우고 다시 연결해야 한다).

메모 3종(사각형/원(타원)/마름모)은 생성 이후 텍스트 편집·이동·크기조절·다중선택·삭제·실행취소·꾸미기가 전부 동일하게 동작한다.
이미 만들어진 메모의 도형(사각형↔원↔마름모) 자체를 나중에 바꾸는 기능은 아직 없다.

모든 도형의 텍스트는 가로/세로 가운데 정렬이다. 원/마름모는 모서리 쪽이 좁아지는 모양 특성상 텍스트 영역을
도형보다 안쪽으로 줄여서(원 15%, 마름모 25% 여백) 어떤 경우에도 글자가 도형 밖으로 삐져나가지 않게 했다.
메모를 선택하면 실제 경계 상자를 점선으로 같이 보여주는데, 원/마름모는 도형 모양이 경계 상자 모서리까지
채우지 않아서 크기조절 핸들과 삭제 버튼이 도형 바깥의 "빈 공간"에 있는 것처럼 보일 수 있기 때문이다 —
점선을 보면 핸들/삭제 버튼이 실제로는 정확한 위치(경계 상자 모서리)에 있다는 걸 확인할 수 있다.

여러 메모에 한 번에 서로 다른 텍스트를 입력하는 기능은 없다. 텍스트 편집은 항상 메모 하나씩 더블클릭해서 한다.

실행취소/다시실행은 메모의 생성·이동·삭제·텍스트 수정·꾸미기(배경색/글자크기/정렬/테두리굵기),
화살표의 생성·삭제·라벨 수정을 기록한다(화면 이동·확대축소는 기록되지 않음). 텍스트/라벨 수정은
글자 하나하나가 아니라 편집을 마치고 밖을 클릭했을 때 한 단계로 기록된다. 기록은 최근 50단계까지만
유지되며, 브라우저를 새로고침하면 초기화된다(저장되는 내용 자체는 유지됨).

각 페이지는 독립적인 무한 캔버스다 — 팬/줌/메모/화살표/선택/실행취소 기록이 페이지마다 따로 관리된다.
페이지를 전환해도 다른 페이지의 실행취소 기록은 그 세션 동안(새로고침 전까지) 유지된다.

전체 구조(폴더 트리 + 모든 페이지의 내용)는 브라우저 `localStorage` 에 자동 저장되어 새로고침해도 유지된다.
(저장 위치는 브라우저별로 분리됨. 다른 브라우저/기기와는 공유되지 않음 — 기기를 옮길 땐 내보내기/가져오기 사용)

이 기능이 생기기 전에 저장돼 있던 캔버스 내용은 처음 열 때 자동으로 "기본 페이지"라는 이름의 페이지로 옮겨온다.

## 기술 스택

- 순수 HTML / CSS / JavaScript, 빌드 도구·서버 없음
- 무한 캔버스는 `#world` 컨테이너에 CSS `transform: translate() scale()` 을 적용해 구현
- 상태: `view = { x, y, scale }` + `notes = [{ id, x, y, w, h, text, shape, bg, fontSize, textAlign, borderWidth }]`(`shape`: `rect` | `ellipse` | `diamond`; `bg`: 커스텀 배경색 hex 또는 `null`=기본값) + `arrows = [{ id, fromId, toId, label? }]` — 이 전체가 페이지 하나의 내용이다
- 메모 꾸미기(배경색/테두리굵기)는 사각형·원·마름모 모두 CSS 변수(`--note-custom-bg`, `--note-border-width`)로 처리한다.
  마름모는 `clip-path` 로 잘린 `::after` 가상요소가 실제 배경/테두리를 담당하는데, 가상요소는 JS에서 직접 인라인
  스타일을 줄 수 없어서 `.note` 엘리먼트에 CSS 변수를 얹어두고 각 도형별 CSS 규칙이 그 변수를 참조하게 만들었다 —
  이렇게 하면 도형이 뭔지 JS 쪽에서 따로 분기하지 않아도 된다. 텍스트 크기/정렬은 `.note-text` 에 직접 인라인
  스타일로 준다
- 여러 페이지: `tree`(폴더/페이지 트리) + `pagesData`(페이지 id → 위 상태 전체)로 관리한다. "페이지 전환"은 지금
  화면에 그려진 내용을 통째로 다른 페이지 것으로 바꿔치기하는 것과 같다(실행취소의 스냅샷 복원과 같은 원리)
- 마름모는 배경 레이어(`.note-shape`)에만 `clip-path` 를 걸어 잘라내고, 텍스트/삭제버튼은 별도 레이어라 잘리지 않게 분리했다
- 화살표는 `#world` 안의 SVG 레이어(`#arrows-layer`)에 그린다. 메모와 같은 부모의 transform 을 그대로 받기 때문에
  팬/줌 때 따로 계산할 필요가 없고, 좌표는 항상 월드 단위로만 다룬다. 연결 지점(상/하/좌/우)은 저장하지 않고
  메모가 움직이거나 크기가 바뀔 때마다 두 메모의 위치를 보고 매번 새로 계산한다
- 화살표 라벨 편집칸은 SVG `<foreignObject>` 안에 진짜 `<input>`을 띄우는 방식이다. arrows-layer 가
  #world 의 자식이라 팬/줌 transform 을 그대로 물려받으므로, 입력칸이 화면 좌표를 따로 계산하지 않아도
  화살표를 따라 움직이고 확대/축소도 자동으로 맞춰진다

## 파일 구조

```
index.html   화면 뼈대
styles.css   스타일 (점 격자 배경, 메모 카드)
app.js       로직 전체 (팬 / 줌 / 생성 / 이동 / 선택 / 삭제 / 실행취소 / 저장)
```
